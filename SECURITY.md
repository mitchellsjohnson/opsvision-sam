# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting: open the repository's **Security** tab and choose
**Report a vulnerability**.

Include a description, reproduction steps, and the affected version or commit.
We aim to acknowledge reports within a few business days and will coordinate a
fix and disclosure timeline with you.

## Supported versions

OpsVision is in early development. Only the `main` branch is supported.
