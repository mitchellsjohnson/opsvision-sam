# OpsVision

OpsVision is an open-source, multi-tenant operational metrics program app. It
provides a versioned metric framework, a monthly close process, dashboards, and
an AI guide named SAM, a wise owl who helps teams understand their numbers.

## Stack

- Frontend: React (`web/`)
- Backend: Go on AWS (`api/`)
- Auth: Auth0
- AI: Amazon Bedrock

## Status

Early development. Interfaces and data models will change.
